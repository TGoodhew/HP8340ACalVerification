# HP-BASIC Reference Files

This directory is intended to store the original HP-BASIC calibration and verification programs for reference.

## Needed Files

The following files are needed to complete the implementation:

1. **Attenuator Calibration Program**
   - Original HP-BASIC program for attenuator calibration
   - Expected to contain the step-by-step calibration procedure
   
2. **Operation Verification Program**
   - Original HP-BASIC program for operation verification tests
   - Expected to contain the verification test sequences

3. **HP 8340A/B Service Manual**
   - Calibration procedures
   - Technical specifications
   - Test procedures and expected results

## Purpose

These files will be used to:
- Understand the original calibration procedures
- Ensure accuracy in the .NET recreation
- Maintain compatibility with HP's specifications
- Document the expected behavior and test points

## File Placement

- Place HP-BASIC files (`.bas`, `.txt`, etc.) directly in this directory
- Add service manual PDF or relevant sections to the `docs/` directory
